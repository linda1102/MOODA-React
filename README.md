# M O O D A — Furniture & Home Decor

M O O D A is a modern furniture and home decor website designed to help users discover stylish furniture and accessories for their living spaces.

The website features a clean and elegant interface with warm neutral colors, maroon accents, and a responsive layout.

## Features

- **Home Page** — Landing page introducing the MODОA brand and featured products.
- **Product Catalog** — Browse available furniture and home decor products.
- **Product Details** — View product information, price, and images.
- **Shopping Cart** — Add products to the cart and manage quantities.
- **Quantity Management** — Increase or decrease the quantity of products.
- **Cart Total** — Automatically calculate the total price.
- **Responsive Design** — Optimized for desktop and mobile devices.
- **Local Storage** — Preserve cart data in the browser.

## Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
